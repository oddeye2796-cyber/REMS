# 제약 바이오 REMS 목업

제약 GMP 제조동의 작업장 환경 모니터링 시스템(REMS, Room Environment Monitoring System) 화면을 클릭해 볼 수 있는 단일 HTML 목업입니다. 룸별 온도·습도·차압·파티클을 평면도 경광등과 표로 실시간 확인하고, 일탈 알림·조치 내역, 수집 데이터 조회·통계 분석, 장비·기준정보, 감사 추적(Audit Trail)까지 다룹니다. 서버나 설치 없이 `index.html`을 브라우저로 열면 됩니다.

- 언어: 한국어 / English / 日本語 (상단 언어 버튼)
- 테마: 다크 / 라이트 (상단 테마 버튼)
- 로그인: 아이디·비밀번호 아무 값이나 입력하면 들어갑니다. 주소 끝에 `#auto`를 붙이면 로그인 화면을 건너뜁니다. 상단 **모바일 화면** 버튼으로 현장 담당자용 휴대폰 화면(룸별 환경 모니터링, 알람 모니터링)을 볼 수 있습니다.
- 데이터: 모든 데이터는 예시이며 브라우저(localStorage)에만 저장됩니다. 좌측 하단 **예시 데이터 초기화**나 브라우저 사이트 데이터 삭제로 처음 상태로 돌아갑니다.

## 화면 구성 (31종 + 모바일 2종)

| 구분 | 화면 |
|---|---|
| 대시보드 | 홈(오늘의 환경 현황, 구역별 룸 상태, 최근 일탈·주의) |
| 모니터링 | 작업장 종합 환경 모니터링(평면도 경광등·룸 상세·센서 추이), 룸별 환경 모니터링 1·2(표·공조기별), 센서 통신상태 모니터링, 파티클·차압 상태·사유등록 |
| 데이터수집관리 | 수집 데이터 조회(온습도·차압·파티클 추이), 환경데이터 수집 로그(엑셀/PDF 로그북), 환경관리기준 일탈이력(조치 내역 입력) |
| 데이터 분석 | 월별·일별 통계분석(트렌드·계절·시간대·일탈 빈도), 상관관계 분석(산점도·선형회귀), 일일 환경 모니터링 보고서 |
| Audit Trail | 사용자 작업 이력, 시스템 자동 처리 이력(변경 전/후) |
| 알림발송관리 | 알림발송이력, 알림 메시지 설정 관리 |
| 장비관리 | 센서·PoE 장비정보(타임서버 IP), 장비유지이력, 센서 알람/부저 설정, 센서 로컬 권한, 파티클 알람/부저 설정 |
| 기준정보관리 | 룸 정보관리, 온습도 환경조건 관리, 차압 환경조건 관리 |
| 시스템 인터페이스 | BMS I/F 관리 |
| 시스템 관리 | 부서·사용자 관리, 팀권한관리(알림 수신 팀), 권한 관리(화면별 등록·읽기·수정·삭제), 공통코드 관리, 시스템 설정 |
